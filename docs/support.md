# Support

For pre-release testing, report reproducible defects through this repository's GitHub Issues with the app version/commit, platform/OS, steps to reproduce, expected result, actual result, and privacy-safe logs or screenshots.

Before public store launch, replace this developer channel with the final public support email/site and record the canonical support URL in release evidence and store metadata. Never post passwords, access tokens, medical records, or other sensitive account data in an issue.

# Privacy policy — pre-release repository version

All-In-One Fitness stores workout, nutrition, water, wellness, body-measurement, target, and account data needed to provide its tracking features. Local-first records are stored on the device and, when cloud synchronization is enabled, are synchronized to the authenticated account's Supabase-backed storage.

The app does not require advertising data or sell fitness records. Service providers used to operate the application may process data only as needed to provide authentication, cloud storage, crash/error reporting, build/distribution, or other explicitly enabled product infrastructure.

Users can export supported account data from **More → Export my data** and can request permanent deletion from **More → Delete account permanently**. Successful deletion removes the authentication account and owned cloud records covered by the database cascade policy, then clears the account's local application data on that device.

Before public launch, replace this repository version with the final policy reviewed for the actual production services, jurisdiction, retention practices, contact address, and store disclosures, and publish the canonical URL required by the stores.
